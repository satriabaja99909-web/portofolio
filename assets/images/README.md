# Folder Gambar (assets/images)

Folder ini disiapkan untuk menyimpan aset gambar lokal portfolio kamu.

### Rekomendasi Nama & Ukuran File:
1. `hero-avatar.jpg` / `profile.jpg`
   - Rasio: 4:5 atau 1:1
   - Resolusi ideal: 1000 x 1250 piksel (dikompresi WebP atau JPG kualitas 80-85%).
2. `project-1.jpg`, `project-2.jpg`, `project-3.jpg`
   - Rasio: 16:10 atau 16:9
   - Resolusi ideal: 1200 x 750 piksel.

### Cara Menggunakan Gambar Lokal di `index.html`:
Cukup ganti atribut `src` pada tag `<img>`:
```html
<!-- Contoh: -->
<img src="assets/images/hero-avatar.jpg" alt="Foto Daifa">
```
Saat ini `index.html` menggunakan gambar editorial terkurasi dari Unsplash CDN yang dapat langsung diganti kapan saja.
